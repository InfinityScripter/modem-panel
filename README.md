# Modem Panel

Веб-панель для старых USB-модемов Huawei (E352, E173, E1550 и похожих, в том числе от Мегафона и МТС) на современном macOS, включая Apple Silicon.

Родная программа Mobile Partner со встроенного диска модема собрана для 32-битных Mac и на новых версиях macOS не запускается. Драйверов для этих модемов в macOS тоже нет. Modem Panel работает с модемом напрямую через USB (libusb), поэтому драйверы не нужны.

## Что умеет

- переключает модем из режима «компакт-диска» в режим модема (macOS спросит пароль администратора);
- показывает статус симки, оператора, регистрацию в сети, тип сети и уровень сигнала;
- отправляет USSD-запросы, например `*100#` для баланса и `*205#` для своего номера; есть кнопки для Мегафона, МТС, Билайна и Т2;
- читает, отправляет и удаляет SMS, в том числе на русском;
- показывает модель, прошивку, IMEI и привязку модема к оператору;
- может навсегда выключить режим «диска» (`AT^SETPORT`): тогда модем сразу включается как модем, и пароль администратора больше не нужен.

- может снять привязку модема к оператору бесплатным кодом по IMEI (папка `unlock/`).

Звонков нет: в операторских прошивках голос обычно выключен.

## Установка и запуск

```sh
brew install libusb
git clone https://github.com/InfinityScripter/modem-panel.git
cd modem-panel
./run.sh
```

Панель откроется в браузере по адресу http://127.0.0.1:18352/. Она слушает только этот компьютер.

## Проверено

Huawei E352 (прошивка 11.102.27.00.209, Мегафон) на macOS 26, Apple Silicon. Другие модемы Huawei с USB-кодом `12d1:1446` и похожими, скорее всего, тоже работают. Если ваш модем не определился, откройте issue с выводом `ioreg -p IOUSB -l -w0 | grep -A3 HUAWEI`.

## Как это устроено

- `modem.py` находит модем, отправляет ему стандартную команду переключения Huawei и обменивается AT-командами через bulk-эндпоинты USB.
- `server.py` — маленький HTTP-сервер на стандартной библиотеке Python. Чужие сайты не могут вызывать его API: запросы с другим `Origin` он отклоняет.
- `index.html` — страница без внешних зависимостей.

## Ограничения

- Пока режим «диска» не выключен, после каждого переподключения модем нужно переключать кнопкой на странице, и macOS спрашивает пароль. Кнопка «Всегда включаться как модем» убирает это навсегда; вернуть старое поведение можно командой `AT^SETPORT` со значением, которое модем показывал раньше (у E352 это `A1,A2;1,2,3,7,A1,A2`).
- Привязку к оператору надёжно видно только с чужой симкой: с родной симкой `AT^CARDLOCK?` отвечает «не привязан», даже если модем залочен.
- Пока панель отправляет команду, другие программы не могут работать с модемом.
- Чтение списка SMS помечает новые сообщения как прочитанные.
- Подключение к интернету через модем панель не настраивает.
